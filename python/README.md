# Python 完整学习路线图

> 交互式、可追踪进度的 Python 学习教程。点击左侧章节导航，逐章学习并打卡。
> 进度保存在浏览器本地存储，刷新不丢失。

## 学习阶段

### 阶段一：入门基础（1-2 周）
1. 环境搭建
2. 变量与数据类型
3. 输入输出
4. 运算符
5. 条件判断
6. 循环
7. 列表
8. 字典
9. 元组与集合
10. 函数基础

### 阶段二：中级进阶（2-3 周）
11. 文件操作
12. 异常处理
13. 模块与包
14. 字符串高级操作
15. 列表推导式
16. 面向对象编程
17. 魔术方法
18. 属性与描述符

### 阶段三：高级特性（3-4 周）
19. 迭代器与生成器
20. 装饰器
21. 上下文管理器
22. Lambda 与函数式编程
23. collections 高级容器
24. 类型注解
25. 多线程与多进程
26. asyncio 异步编程

### 阶段四：工程化实践（2-3 周）
27. 项目结构与依赖管理
28. 单元测试
29. 代码质量工具
30. 日志与调试
31. 打包与发布

### 阶段五：主流框架方向（选学）
32. FastAPI - Web API
33. Flask - 轻量 Web 框架
34. Pandas - 数据分析
35. 爬虫基础
36. 自动化办公
37. 常用标准库速查
